# Démarrage rapide ANDREA

Bienvenue. Ce guide vous accompagne du téléchargement à votre première
session avec votre formateur virtuel.

## 1. Installation

### macOS

1. Téléchargez le fichier `.dmg` correspondant à votre Mac depuis
   [github.com/Julien-dao/Lelins/releases](https://github.com/Julien-dao/Lelins/releases) :
   - **Apple Silicon (M1, M2, M3, M4)** → `ANDREA-…aarch64.dmg`
   - **Mac Intel** → `ANDREA-…x86_64.dmg`
2. Double-cliquez sur le fichier téléchargé.
3. Glissez l'icône **ANDREA** dans le dossier **Applications**.
4. Lancez ANDREA depuis Launchpad ou Spotlight.

> macOS peut afficher un avertissement la première fois (« développeur non
> identifié »). Faites un clic-droit sur ANDREA dans le dossier Applications,
> choisissez **Ouvrir**, puis **Ouvrir** dans la boîte de dialogue. Cette
> étape n'est nécessaire qu'une seule fois.

### Windows

1. Téléchargez l'installeur `ANDREA-…x64-setup.msi`.
2. Double-cliquez et suivez l'assistant d'installation.
3. Lancez ANDREA depuis le menu Démarrer.

## 2. Première activation

Au premier lancement, ANDREA vous demande :

1. **Votre clé de licence**, reçue par email après votre achat sur Gumroad.
   Format : `ANDREA-DECO-XXXXX-XXXXX-XXXXX-XXXXX`. Saisissez-la dans le
   champ. Si vous l'avez perdue, retrouvez-la dans votre historique
   Gumroad.
2. **Votre email d'achat**, qui sécurise votre clé.

Si tout est validé, vous accédez au téléchargement du moteur.

## 3. Téléchargement du moteur (~5 à 14 Go)

ANDREA télécharge automatiquement les composants nécessaires :

- Le modèle d'intelligence artificielle adapté à votre machine ;
- Le moteur de reconnaissance vocale (Whisper) ;
- Les voix de synthèse vocale (Piper).

Le téléchargement ne se fait **qu'une seule fois**. Vous pouvez fermer
l'application en cours de route ; la reprise est automatique.

> **Espace requis** : ~20 Go libres sur le disque où ANDREA est installée.
> Sur connexion fibre, prévoir 15 à 30 minutes. Sur ADSL, jusqu'à 2 heures.

## 4. Onboarding personnalisé

ANDREA vous pose quelques questions pour s'adapter à vous :

- Votre prénom et comment vous souhaitez être appelé·e.
- Votre forme d'adresse préférée (`tu` ou `vous`).
- Votre contexte (apprenant·e en CFA, candidat·e VAE, formateur·rice en
  exercice, en reconversion, …).
- Votre objectif (titre complet, CCP1 seul, montée en compétences sans
  certification, …).
- Votre cadence souhaitée.
- Votre date d'épreuve si elle est connue.

Ces réponses sont **strictement locales** et restent sur votre ordinateur.

## 5. Choix du formateur virtuel

Vous personnalisez ANDREA :

- **Avatar** : 12 portraits proposés (dont représentations ultramarines),
  ou téléversez votre propre photo.
- **Voix** : 4 voix françaises proposées avec écoute préalable.
- **Nom du formateur** : conserver `ANDREA` ou personnaliser.

Tous ces choix sont modifiables à tout moment dans **Paramètres**.

## 6. Première session

ANDREA vous accueille avec une session guidée pour vous présenter ses
trois rôles : **former**, **évaluer**, **guider**. Vous pouvez ensuite
naviguer librement entre les espaces (sidebar à gauche).

## 7. Au quotidien

- Posez vos questions en texte ou en vocal (bouton micro).
- ANDREA cite ses sources : « Source : REAC V07 21/12/2022, CCP1, CP3 ».
- Notez ce que vous voulez dans **Mon coffre-fort**.
- Suivez votre avancée dans **Ma progression**.
